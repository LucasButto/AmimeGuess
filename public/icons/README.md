# Íconos

Recortes de las hojas de íconos que aportó el usuario (originales en `data-src/<serie>/icons/`). Un WebP por icono, con fondo
transparente, cuadrado y con 4 px de margen. Se regeneran con `python scripts/design/recortar-iconos.py`.

- `pokemon/` — 36 objetos (Pokédex, mochila, piedras, fósiles…). `pokemon/pokebolas/`: las 38 Poké Balls.
- `naruto/` — 36 objetos (kunai, bandas, máscaras, ojos, jutsus…).
- `dragon-ball/` — 36 objetos (las 7 esferas, radar, nave, cápsulas…).
- `yugioh/` — 36 objetos (artilugios del milenio, cartas, monstruos…). `yugioh/jeroglificos/`: 36 jeroglíficos de un solo color
  (marrón), pensados para usarse como máscara (`mask-image`) y tomar el color del texto.

Los nombres de los íconos son orientativos. Orígenes y licencias: ver `/creditos` y `docs/DESIGN.md` ("A confirmar").
